The full flow
sequenceDiagram participant U as Customer participant SC as StripeOrderController participant E as EventDispatcher participant CS as CheckoutSessionService participant SK as Stripe API U->>SC: Click "Pay with Stripe" SC->>E: dispatch(StripeCheckoutSessionRequestEvent) E->>CS: handle() (contract=DRAFT) CS->>CS: build BasketSnapshot CS->>CS: contract.transitionTo(NOT_FINISHED) CS->>CS: order = createOrder(NOT_FINISHED) CS->>SK: checkout.sessions.create(metadata={order_id}) SK-->>CS: session.url CS-->>U: 303 redirect → checkout.stripe.com U->>SK: pay (card / SCA / wallet) SK-->>U: 303 redirect → success_url U->>SC: GET /cl=stripeorder?fnc=return SC->>E: dispatch(StripeCheckoutReturnEvent) E->>CS: advance contract → READY_TO_COMMIT E->>SC: finalize order → FULFILLED SC-->>U: redirect → cl=thankyou
Guarantees
  • Order ID first. OXID row exists in NOT_FINISHED before Stripe sees the customer.
  • Idempotent return. No-op when contract is already FULFILLED.
  • Webhook safety net closes the order if the browser dies.
  • Language preserved via lang in success_url.
  • 3DS inline — Stripe owns the SCA challenge.
