Testable subclass pattern

OXID admin controllers don’t support constructor DI — OrderRefund extends Order_parent. To unit-test them we extend with a constructor that skips OXID bootstrap and accepts dependencies directly. 

class TestableOrderRefund extends OrderRefund {
    public function __construct(
        ?Order $o = null,
        ?ViewDataProvider $v = null
    ) { /* no parent::__construct */ }

    public function getOrder(): ?Order
    { return $this->testOrder; }
}
TDD on bug fixes is not optional. Every bug fix begins with a failing test that reproduces the bug. The compounding payoff: the same test guards the fix against regression for the lifetime of the module.
