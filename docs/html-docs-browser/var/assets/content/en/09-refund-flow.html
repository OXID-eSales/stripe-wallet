Refund: validated, audited, idempotent.
Money never leaves twice.

Validated against captured minus prior refunds in cents — never floats. Each refund writes a transaction row, dispatches PaymentRefundedEvent, fans out to OpalReturns & subscribers.

RefundService · the path
public function refund(
    PaymentContract $c,
    ?float $amount = null,
    ?string $reason = null
): RefundResult {
    $i = $this->adapter->retrievePaymentIntent(
        $c->getProviderIntentId()
    );

    $cents = $amount === null
        ? $this->helper->remainingRefundable($i)
        : (int) round($amount * 100);

    $this->helper->assertRefundable($i, $cents);

    $r = $this->adapter->refundCharge(
        $i->latest_charge, $cents, $reason
    );
    $this->dispatcher->dispatch(
        new PaymentRefundedEvent($c, $r)
    );
    return RefundResult::fromRefund($r);
}
RefundHelper
  • remainingRefundable() = captured - Σ priorRefunds
  • assertRefundable() throws if > remaining or ≤ 0
  • Pure, integer-only, fully unit-tested
Idempotency · no double-refunds
  • Admin form posts CSRF + unique request_id

        PaymentRefundedEvent $e,
        EventContext $ctx

            $e->getContract(),
            $e->getAmountCents()
        );
    }
