From clean checkout to a live test payment in under five minutes

Installation in three command groups.
Composer, the OXID console, then Stripe keys.

1Composer

  • Payment Base first — it owns the tables
  • Dev dependency: stripe/stripe-php ^19.3
$ composer require \
    oxid-esales/payment-base \
    oxid-esales/stripe-wallet

2OXID console

  • Activation registers the Stripe tab via metadata.php
  • Cache clear re-builds DI container & Twig templates
  • No Doctrine migrations — tables come from Payment Base
$ bin/oe-console oe:module:install extensions/stripe
$ bin/oe-console oe:module:activate oe_payments_stripe_wallet
$ bin/oe-console oe:cache:clear

3Stripe keys + webhook

Admin → Extensions → OE Payments · Stripe. Webhook URL:

https://{shopUrl}/index.php?cl=StripeWebhookController 
Mode:             test
Test secret key:  sk_test_…
Test publishable: pk_test_…
Webhook secret:   whsec_…
Capture mode:     automatic
Smoke test in 30 s. Order with 4242 4242 4242 4242 → thank-you, capture transaction in the Stripe tab, contract FULFILLED. Missing any of the three? The Diagnose button tells you which guard, handler, or webhook failed.
