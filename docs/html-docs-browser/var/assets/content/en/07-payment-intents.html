PaymentIntent states.
Mapped to contract transitions, 1-to-1.

Stripe represents every payment as a PaymentIntent with its own state machine. PaymentIntentHelper is the only class that knows how to translate Stripe state → contract transition. Adding a state means changing one switch — nowhere else.

PaymentIntentHelper API
final class PaymentIntentHelper
{
    public function isCaptured(PaymentIntent $pi): bool;
    public function amountCaptured(PaymentIntent $pi): int;
    public function amountRefunded(PaymentIntent $pi): int;
    public function isAuthorizedOnly(PaymentIntent $pi): bool;
    public function isCanceled(PaymentIntent $pi): bool;

    public function deriveContractTransition(
        PaymentIntent $pi,
        PaymentContract $contract
    ): ?ContractState;
}
Why minor units everywhere
  • Stripe amounts are always integer minor units (cents) — no floats on the wire.
  • OXID basket totals come as floats — converted once in CheckoutHelper via round($eur * 100).
  • Refund math (amountRefunded() <= amountCaptured() - sumPriorRefunds) lives in RefundHelper, in cents.
