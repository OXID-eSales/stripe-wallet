PaymentIntent states.
Mapped to contract transitions, 1-to-1.

PaymentIntentHelper is the only class that knows how to translate Stripe state → contract transition. Adding a state means changing one switch — nowhere else.

Stripe PaymentIntent → contract
Stripe state Contract
requires_payment_methodstay NOT_FINISHED
requires_action→ Stripe3DSRequiredEvent
requires_capture→ AUTHORIZED
succeeded→ FULFILLED
canceled→ CANCELLED
processingstay PENDING
Capture mode
  • automatic → intent.capture_method = "automatic" → succeeded directly
  • manual → intent.capture_method = "manual" → requires_capture · admin captures later
PaymentIntentHelper API
  • isCaptured() · isAuthorizedOnly() · isCanceled()
  • amountCaptured() · amountRefunded()
  • deriveContractTransition($pi, $contract): ?ContractState — the one switch
Minor units everywhere
  • Stripe amounts: integer minor units (cents). No floats on the wire.
  • OXID basket totals are floats — converted once in CheckoutHelper via round($eur * 100).
  • Refund math: refunded ≤ captured - Σ priorRefunds — in RefundHelper, integer-only.
