Testable-Subclass-Pattern

OXID-Admin-Controller unterstützen keine Constructor-DI — OrderRefund extends Order_parent. Um sie unit-zu-testen, erweitern wir sie mit einem Konstruktor, der den OXID-Bootstrap überspringt und Abhängigkeiten direkt entgegennimmt. 

class TestableOrderRefund extends OrderRefund {
    public function __construct(
        ?Order $o = null,
        ?ViewDataProvider $v = null
    ) { /* kein parent::__construct */ }

    public function getOrder(): ?Order
    { return $this->testOrder; }
}
TDD bei Bugfixes ist nicht optional. Jeder Bugfix beginnt mit einem fehlschlagenden Test, der den Bug reproduziert. Compounding-Effekt: Derselbe Test sichert den Fix gegen Regressionen für die Lebenszeit des Moduls.
