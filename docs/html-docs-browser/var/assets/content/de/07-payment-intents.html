PaymentIntent-Zustände.
1:1 auf Vertragsübergänge abgebildet.

PaymentIntentHelper ist die einzige Klasse, die Stripe-Zustand → Vertragstransition übersetzt. Ein neuer Zustand bedeutet eine einzige Switch-Änderung — sonst nichts.

Stripe-PaymentIntent → Vertrag
Stripe-Status Vertrag
requires_payment_methodbleibt NOT_FINISHED
requires_action→ Stripe3DSRequiredEvent
requires_capture→ AUTHORIZED
succeeded→ FULFILLED
canceled→ CANCELLED
processingbleibt PENDING
Capture-Modus
  • automatic → intent.capture_method = "automatic" → sofort succeeded
  • manual → intent.capture_method = "manual" → requires_capture · Admin bucht später
PaymentIntentHelper-API
  • isCaptured() · isAuthorizedOnly() · isCanceled()
  • amountCaptured() · amountRefunded()
  • deriveContractTransition($pi, $contract): ?ContractState — der eine Switch
Durchgängig in Cent
  • Stripe-Beträge: Integer-Cent. Keine Floats auf dem Draht.
  • OXID liefert Floats — einmalig in CheckoutHelper via round($eur * 100) konvertiert.
  • Refund-Mathematik: refunded ≤ captured - Σ priorRefunds — im RefundHelper, Integer-only.
