Stripes Sprache — auf unseren Vertrag gemappt

PaymentIntent-Zustände.
1:1 auf Vertragsübergänge abgebildet.

Stripe modelliert jede Zahlung als PaymentIntent mit eigener Zustandsmaschine. PaymentIntentHelper ist die einzige Klasse, die Stripe-Zustand → Vertragstransition übersetzt. Ein neuer Zustand bedeutet eine einzige Switch-Änderung — sonst nichts.

PaymentIntentHelper-API
final class PaymentIntentHelper
{
    public function isCaptured(PaymentIntent $pi): bool;
    public function amountCaptured(PaymentIntent $pi): int;
    public function amountRefunded(PaymentIntent $pi): int;
    public function isAuthorizedOnly(PaymentIntent $pi): bool;
    public function isCanceled(PaymentIntent $pi): bool;

    public function deriveContractTransition(
        PaymentIntent $pi,
        PaymentContract $contract
    ): ?ContractState;
}
Warum durchgängig in Cent
  • Stripe-Beträge sind immer Integer-Cent — keine Floats auf dem Draht.
  • OXID liefert Floats; einmal in CheckoutHelper via round($eur * 100) konvertiert.
  • Refund-Mathematik (amountRefunded() <= amountCaptured() - sumPriorRefunds) liegt im RefundHelper, in Cent.
