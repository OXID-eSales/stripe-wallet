Bestelldetails → Stripe-Tab

Ein Tab. Fünf Karten. Null DB-Snapshots.
Die Stripe-API ist die Quelle der Wahrheit.

Der Stripe-Tab wird von OrderRefund gerendert: Capture, Refund, Cancel-Auth, Reconcile. Anzeige zieht Live-Daten von Stripe; die lokale DB ist Audit-Log, nicht Cache.

Was im Tab erscheint
  • Payment Details — Vertrags-ID, Bestell-ID, Transaction-ID-Link, Captured / Refunded
  • Transaktionsverlauf — live aus Stripe mit farbigen Badges
  • Capture-Formular — teilbar
  • Refund-Formular — prüft Restbetrag
  • Autorisierung stornieren — gibt offene Auth frei
Speicher-Strategie · B+
  • Anzeige: Stripe-API — auch Dashboard-Aktionen
  • Audit-Log: oe_payments_transaction
  • Self-Healing: reconcilePaymentState() korrigiert OXPAID-Drift
Controller-Dispatch · eine Aktion je Submit
public function dispatch(
    Order $o, string $action, array $req
): void {
    match ($action) {
        'capture' => $this->d->dispatch(
            new StripeCaptureRequestEvent(
                $o, $this->amount($req))),
        'refund'  => $this->d->dispatch(
            new StripeRefundRequestEvent(
                $o, $this->amount($req))),
        'cancel'  => $this->d->dispatch(
            new StripeCancelAuthorizationRequestEvent($o)),
    };
}
