Refund: validiert, geloggt, idempotent.
Geld geht nie zweimal raus.

Validiert gegen Captured minus vorheriger Erstattungen in Cent — nie in Floats. Jede Erstattung schreibt eine Transaktionszeile, dispatcht PaymentRefundedEvent, fächert zu OpalReturns auf.

RefundService · der Pfad
public function refund(
    PaymentContract $c,
    ?float $amount = null,
    ?string $reason = null
): RefundResult {
    $i = $this->adapter->retrievePaymentIntent(
        $c->getProviderIntentId()
    );

    $cents = $amount === null
        ? $this->helper->remainingRefundable($i)
        : (int) round($amount * 100);

    $this->helper->assertRefundable($i, $cents);

    $r = $this->adapter->refundCharge(
        $i->latest_charge, $cents, $reason
    );
    $this->dispatcher->dispatch(
        new PaymentRefundedEvent($c, $r)
    );
    return RefundResult::fromRefund($r);
}
RefundHelper
  • remainingRefundable() = captured - Σ priorRefunds
  • assertRefundable() wirft, wenn > verbleibend oder ≤ 0
  • Rein, Integer-only, vollständig unit-getestet
Idempotenz · keine Doppel-Refunds
  • Admin-Formular postet CSRF + eindeutige request_id
  • oe_payments_idempotency mit Schlüssel (contract_id, request_id) — Replay gibt vorheriges Ergebnis zurück
  • SDK-Call trägt Idempotency-Key — Stripe weist Duplikate ab
