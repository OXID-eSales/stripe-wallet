Capture: voll, teilweise oder nie.
Der Vertrag bildet die Realität ab, nicht die Absicht.

Im Automatik-Modus erfolgt das Capture sofort. Im Manual-Modus bleibt der Vertrag in AUTHORIZED, bis ein Admin bucht — teilweise, voll oder gar nicht.

CaptureService · der Pfad
public function capture(
    PaymentContract $c,
    ?float $amount = null
): CaptureResult {
    $i = $this->adapter->retrievePaymentIntent(
        $c->getProviderIntentId()
    );

    $cents = $amount === null
        ? $i->amount
        : (int) round($amount * 100);

    $this->validator->assertCanCapture($i, $cents);

    $r = $this->adapter->capturePaymentIntent(
        $i->id, amount_to_capture: $cents
    );
    $this->dispatcher->dispatch(
        new PaymentCapturedEvent($c, $r)
    );
    return CaptureResult::fromIntent($r);
}
Validator-Gates
  • Intent ist requires_capture oder succeeded
  • Betrag ≤ intent.amount_capturable und > 0
  • Vertrag besitzt diese provider_intent_id
Teil-Capture — Nebenwirkungen
  • Auth-Freigabe. Stripe gibt den nicht gebuchten Rest dem Kunden zurück.
  • Vertragsfeld captured_amount wird vom PaymentCapturedHandler aktualisiert.
  • OXPAID gesetzt; Reconciliation heilt Drift automatisch.
  • Transaktionszeile in oe_payments_transaction.
