- Sprint: `sprints/COUPON-payment-switch-and-release.md` (OPC-175, ASD-STE100). The customer applies a coupon in OPC, changes the payment method (e.g. Mollie → Stripe) and the coupon disappears. Root cause: the earlier early order still holds the voucher row (`oxvouchers.OXORDERID`); core `calcVoucherDiscount()` drops it silently and `validateVouchers()` refuses the next order (`VOUCHERERROR`). Also found: a Mollie webhook `canceled`/`failed`/`expired` only sets `OXTRANSSTATUS` (no storno, voucher never released); PayPal `VOIDED` cancels only the contract. Local DB, last 14 days: 245 Stripe, 60 PayPal, 13 Mollie orders still `NOT_FINISHED`.
